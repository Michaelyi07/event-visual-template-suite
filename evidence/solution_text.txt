Delivery form: per the accepted scope the client supplies Figma access at handoff, and the brief allows "Figma link or source files". This package ships the templates as exact-size, Figma-importable source files plus the full revised variable collection - no credentials needed to review or use:
- tokens/tokens.json is W3C DTCG format and imports 1:1 via the Tokens Studio plugin -> 15 color variables + 28 typography styles (Figma variables do not support the typography composite type, so text styles land as styles).
- Each templates/*.html opens pixel-exact in a browser and imports into Figma via the community plugin html.to.design (free tier: 10 imports/month; enable its auto-layout import option) preserving auto-layout frames. Layer names match roles: title, subtitle, badge, hero, qr-slot, logo-safe.
- templates/_badge_labels.json defines the component variant property: event_type = public / member-only / closed-door; color pairs live in the color.badge.* tokens. build_templates.py regenerates everything from tokens + layout spec.
